Download the CA

  • agentry-ca.crt
  • agentry-ca.pem
  • {{.Profile}} (iPhone, iPad)

The same certificate in each: .crt for phones, Windows and macOS, .pem for Linux, and a profile for iOS.

Install it

Android

  1. Download agentry-ca.crt.
  2. Settings > Security (or Security & privacy) > More security settings > Encryption & credentials > Install a certificate > CA certificate > Install anyway, and choose agentry-ca.crt.

iPhone and iPad

  1. Open this page in Safari and download agentry.mobileconfig; allow it.
  2. Settings > Profile Downloaded (or General > VPN & Device Management) > {{.Name}} > Install.
  3. Settings > General > About > Certificate Trust Settings, and turn on full trust for {{.Name}}.

macOS

  1. Download agentry-ca.crt and open it: Keychain Access adds it. Choose the System keychain.
  2. In Keychain Access, open {{.Name}} > Trust > When using this certificate: Always Trust.

Or in Terminal:

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain agentry-ca.crt

Windows

From a Command Prompt run as administrator:

certutil -addstore -f Root agentry-ca.crt

Or open agentry-ca.crt > Install Certificate > Local Machine > Place all certificates in the following store > Trusted Root Certification Authorities.

Linux

Debian and Ubuntu (the file must be PEM, named .crt):

sudo cp agentry-ca.pem /usr/local/share/ca-certificates/agentry-ca.crt
sudo update-ca-certificates

Fedora, Arch and others with p11-kit:

sudo trust anchor --store agentry-ca.pem

Chrome and Edge

They use the system's trusted certificates on Windows, macOS, Android, iOS and ChromeOS, so the steps above are enough. On Linux, Chrome keeps its own list: open chrome://certificate-manager, then Local certificates > Custom > Installed by you > Trusted certificates > Import, and choose agentry-ca.crt. Older versions: Settings > Privacy and security > Security > Manage certificates > Authorities > Import, and tick trust for websites.

Firefox

Settings > Privacy & Security > Certificates > View Certificates > Authorities > Import, choose agentry-ca.crt and tick "Trust this CA to identify websites". Or, on Windows and macOS, set security.enterprise_roots.enabled to true in about:config to use the system's. Firefox for Android: Settings > About Firefox, tap the logo five times, then Settings > Secret Settings > Use third party CA certificates.
