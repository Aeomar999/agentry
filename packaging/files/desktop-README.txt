Agentry desktop app
===================

Agentry's page in a window of its own: the same Agentry as Start Agentry,
with no browser needed.

Open
----
{{OPEN}}

It uses the Agentry already running on this computer (the one in .agentry
in your home folder, such as Start Agentry's), or else starts its own,
for this computer only, {{SERVER}} The window opens signed in.

{{FIRST}}

Quit
----
Close the window, or Quit in the File menu. Quitting stops Agentry only if
the app started it; an Agentry that was already running keeps running.

Links that leave Agentry open in your browser. File, Open in browser opens
Agentry's page there too.

If Agentry doesn't start
------------------------
The server the app starts writes its log to {{LOG}}.
When it doesn't start, the window says so and shows the last lines it
wrote there.
